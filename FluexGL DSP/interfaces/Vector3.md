# Vector3

A 3D vector.

```ts
interface Vector3 {
    x: number;
    y: number;
    z: number;
}
```

## About
Used for positions and directions in 3D, for example by [``SpatialAudioSource``](../classes/SpatialAudioSource.md) and [``SpatialAudioListener3D``](../classes/SpatialAudioListener3D.md). Any object with ``x``, ``y`` and ``z`` works, including a three.js ``Vector3``.

## Properties
- `x`: `number`
- `y`: `number`
- `z`: `number`
