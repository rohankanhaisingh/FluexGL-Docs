# Vector2

A 2D vector.

```ts
interface Vector2 {
    x: number;
    y: number;
}
```

## About
Used for positions in 2D, for example by [``SpatialAudioListener``](../classes/SpatialAudioListener.md). Any object with ``x`` and ``y`` works, including vectors from FluexGL or three.js.

## Properties
- `x`: `number`
- `y`: `number`
